NOTAS
---------------------------------------------------------------------------
- Si estado=false, leer "mensaje" (documento no encontrado, key invalida, etc.).
- Windows cmd: usar comillas dobles como en los ejemplos (la URL lleva & y debe
  ir entre comillas si no, cmd corta el comando).
- Como el POS la llama con fetch directo desde el navegador, la key es visible
  en el bundle JS (SunatLookupCommand). PENDIENTE conocido del proyecto:
  moverla a configuracion del servidor y consumir via CRT (TaxpayerLookup).
- Uso de la key: es la cuenta del proyecto en perudevs.com (plan con limite de
  consultas; si devuelve error de cuota, revisar el plan en su dashboard).
